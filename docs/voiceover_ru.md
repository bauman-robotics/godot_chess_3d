# Озвучка: «11 ходов»

Фактическая дорожка: Yandex SpeechKit, голос **filipp**, скорость 0.96 (отдельные реплики
подогнаны под окно). Таймкоды — реальные, из `vo/lines.json`.

## Тон

Не «спортивный комментатор», а **аудиогид в музее, где выставлен один-единственный экспонат — эта партия**.
Спокойно, чуть отстранённо, с интонацией человека, который изо всех сил сохраняет серьёзное лицо.
Сарказм — не в громкости, а в паузах: сказал — выдержал — пошёл дальше.

- Темп: 145–160 слов в минуту. Медленнее, чем кажется комфортным.
- Пауза перед последним словом реплики — 0,4–0,6 с.
- Никогда не смеяться над собственной шуткой.
- Числа проговаривать чётко, без скороговорки.

## Технические заметки

- Голос: `filipp`, 48 кГц, mp3 64 кбит/с — исходники в `vo/lines/01..20.mp3`.
- Шахматная нотация проговаривается по-русски: `h2` → «аш два», `c6` → «цэ шесть», `Nh4` → «конь на аш четыре».
- Перегенерация: `python3 tools/tts_build.py --voice filipp --speed 0.96`.
- Пересборка звука без перерендера: `python3 tools/mix_audio.py --music "..." --out ...`.
- Музыка: Гендель, «Сарабанда», 0:00–2:54, −16 LUFS, проседает под речью (sidechain, ratio 6).
